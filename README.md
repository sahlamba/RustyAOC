# RustyAOC

Learn Rust concepts by solving AOC problems: https://adventofcode.com

### Useful Commands

```bash
# check compilation
cargo check
# check compilation and create executable
cargo build
# compile, bin, and run
cargo run

# check compilation for specific bin
cargo check --bin 2023_day01
# check compilation and create executable for specific bin
cargo build --bin 2023_day01
# compile, bin, and run specific bin
cargo run --bin 2023_day01
```
